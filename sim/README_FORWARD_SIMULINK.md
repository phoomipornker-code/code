# แก้โมเดลแมทแลปให้ตรง Forward ในเฟิร์มแวร์ v4

ภาพที่ใช้อยู่เป็น **PI สองลูปขนาน แล้ว Switch เลือก duty**  
โค้ดล่าสุด **ไม่ใช่แบบนั้น** — แค่เปลี่ยน 56.8 / 55.8 / Kp / Ki แล้วยังจำลองคนละระบบ

เฟิร์มแวร์แท็ก: `cv58-boost-v14-forward-pi-v4`

## สิ่งที่ต้องรื้อในภาพ (สำคัญกว่าตัวเลข)

| ในภาพตอนนี้ | ต้องเป็นในโค้ด |
|---|---|
| ลูป CV ออก **Duty** | ลูป CV ออก **Iref (แอมป์)** 0–3 A |
| ลูป CC ออก **Duty** | ลูป CC/กระแส ออก **Δduty** (นับ LEDC ต่อ 20 ms) แล้วบวกเข้าตัวสะสม |
| Switch เมื่อ `V_OUT > 55.8` | SoftStart → CC → CV มี **ฮิสเทอรีซิส** เข้า 57.10 ออก 56.40 + ยืนยันเวลา |
| ทั้งสองลูปรันพร้อมกัน | ช่วง CC ใช้แค่ PI กระแส / ช่วง CV ซ้อน PI แรงดัน→กระแส |
| Ts ของ PI = คาบ PWM? | **Ts ตัวควบคุม = 0.02 s** (50 Hz) PWM แค่ 67 kHz ที่คอมเปเรเตอร์ |

## ค่าที่ต้องเปลี่ยนถ้าเก็บโครง Switch ไว้ชั่วคราว (ไม่แนะนำ)

ถ้ายังไม่พร้อมรื้อ cascade อย่างน้อยอย่าใช้ค่าในภาพ:

| บล็อกในภาพ | ค่าในภาพ | ค่าในโค้ด | หมายเหตุ |
|---|---|---|---|
| Constant บน (CV) | 56.8 | **57.60** | เป้าโวลต์ |
| Constant ล่าง (CC) | 5 | 5 | เป้ากระแสถูกแล้ว |
| Switch | > 55.8 | เข้า **57.10** ออก **56.40** | ต้องเป็น Relay/ฮิสเทอรีซิส ไม่ใช่จุดเดียว |
| CV Kp | 25 | **0.70** | ในโค้ดลูปนี้ได้ **แอมป์** ไม่ใช่ duty |
| CV Ki | 4 | **0.35** | คูณ `dt=0.02` ในอินทิกรัล |
| CC Kp | 0.5 | **8.0** | ได้ **Δduty ดิบ** ไม่ใช่ 0–1 |
| CC Ki | 17 | **35.0** | เช่นกัน |
| Sat สุดท้าย | 0–1? | **0–460 / 1023 ≈ 0.450** | `MAX_DUTY_FORWARD` |
| PWM carrier | ? | **67 kHz** | คาบ 14.9 µs ไม่ใช่ Ts ของ PI |

เกนในภาพใช้กับ **duty ทศนิยม 0–1**  
เกนในโค้ดใช้กับ **นับ PWM 0–1023 ต่อรอบ 20 ms** — ห้ามไปวาง Kp=8 ลงบนลูปที่ออก 0–1 โดยตรง

## โครงที่ควรสร้างใหม่ใน Simulink

```text
        Vref=57.60
            │
            ▼
     ┌─────────────┐   sat 0..3 A
     │ PI แรงดัน   │ Kp=0.70  Ki=0.35
     │ (โหมด CV)   │
     └──────┬──────┘
            │ Ireq
            ▼ slew 0.06 A / 0.02 s
          Iref ─── โหมด CC: Iref = 5 A (taper ตั้งแต่ 56.40 V)
            │
            ▼
     Iref − I_OUT
            │
     ┌─────────────┐   sat −20..+25 (นับ/ติ๊ก)
     │ PI กระแส    │ Kp=8  Ki=35
     └──────┬──────┘
            │ Δduty
            ▼
     duty = sat(duty + Δduty, 0, 460)   ← slew ขึ้น 3 ลง 5
            │
            ▼
     D = duty / 1023
            │
            ▼
     D >= carrier(67 kHz)  →  PWM
```

สลับโหมด (แทน Switch 55.8):

```text
SoftStart  2 s หรือ Ibat≥0.35 A  →  CC
CC และ V≥57.10 นาน 200 ms (หรือ V≥57.30)  →  CV
CV และ V≤56.40 นาน 5 s  →  CC
CV และ V≥57.40 และ I≤0.50 A นาน 60 s  →  DONE
```

Anti-windup ของ PI ต้อง **แช่อินทิกรัลตอนอิ่มตัว** เหมือน `boostRunPI` ในเฟิร์มแวร์
