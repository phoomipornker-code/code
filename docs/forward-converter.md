# วงจรฟอร์เวิร์ดคอนเวอร์เตอร์ (Forward Converter)

## 1. ภาพรวม

**Forward Converter** เป็นสวิตชิ่งคอนเวอร์เตอร์ชนิด **isolated** ที่ส่งพลังงานจากปฐมภูมิไปยังทุติยภูมิ **ขณะสวิตช์เปิด (ON)** จึงต่างจาก Flyback ที่เก็บพลังงานในหม้อแปลงแล้วคายตอน OFF

โครงสร้างพื้นฐานได้มาจาก **Buck Converter** โดยแทรกหม้อแปลงเพื่อแยกกราวนด์และปรับอัตราส่วนแรงดัน

เหมาะกับช่วงกำลังประมาณ **50 W – หลายร้อย W** และเมื่อต้องการ isolation กับประสิทธิภาพดีกว่า Flyback ในโหลดปานกลาง–สูง

---

## 2. วงจรพื้นฐาน (Single-Ended Forward + Reset Winding)

```text
                    Np : Ns          D1 (forward)
   Vin ○──┬── L_p ──┬──────)(||)─────┬──►|──┬──────┬── L ──┬── Vo
          │         │      )(||)     │      │      │       │
          │         │  Nr  )(||) Ns  │      │     C_o     R_load
          │         │      )(||)     │      ▼      │       │
          │      Q1 ┴      )(||)     │     D2      │       │
          │         │      )(||)     │   (freewheel)       │
          │         ▼                │      │      │       │
   GND ○──┴─────────┴────────────────┴──────┴──────┴───────┘

   Reset path (tertiary / reset winding Nr):
          Vin ○──►|── L_r (Nr) ── (เชื่อมกับหม้อแปลง) ── GND
```

### องค์ประกอบหลัก

| สัญลักษณ์ | บทบาท |
|-----------|--------|
| **Q1** | สวิตช์หลัก (MOSFET) ควบคุม duty cycle |
| **หม้อแปลง** | แยกกราวนด์ + แปลงแรงดัน; ต้องมีทางรีเซ็ตฟลักซ์ |
| **D1** | ไดโอดฟอร์เวิร์ด — ส่งพลังงานตอน Q1 เปิด |
| **D2** | ไดโอดฟรีวีล — รักษากระแสใน L ตอน Q1 ปิด |
| **L, C_o** | ตัวกรอง LC ด้านเอาต์พุต (เหมือน Buck) |
| **Reset winding / RCD / active clamp** | รีเซ็ตฟลักซ์แมกเนไทซิ่งของหม้อแปลง |

---

## 3. หลักการทำงาน

### ช่วงที่ 1: Q1 เปิด (\(0 < t < DT_s\))

1. แรงดัน \(V_{in}\) ตกคร่อมขดปฐมภูมิ → ฟลักซ์ในแกนเพิ่มขึ้น
2. แรงดันทุติยภูมิ \(v_s = V_{in} \cdot (N_s/N_p)\) ทำให้ **D1 นำ** และ **D2 ตัด**
3. พลังงานไหลผ่าน D1 เข้าตัวกรอง LC ไปยังโหลด
4. กระแสมากเนไทซิ่ง \(i_m\) ในหม้อแปลงเพิ่มขึ้นเชิงเส้น

### ช่วงที่ 2: Q1 ปิด (\(DT_s < t < T_s\))

1. แรงดันทุติยภูมิกลับขั้ว → **D1 ตัด**
2. กระแสในตัวเหนี่ยวนำ L ไหลต่อผ่าน **D2** (ฟรีวีล)
3. พลังงานแมกเนไทซิ่งต้องถูก **รีเซ็ต** (ผ่าน reset winding / clamp) ไม่เช่นนั้นแกนจะอิ่มตัว
4. เมื่อรีเซ็ตเสร็จ ฟลักซ์กลับสู่ศูนย์ก่อนรอบถัดไป

## 4. สมการสำคัญ

### แรงดันเอาต์พุต (CCM, อุดมคติ)

\[
V_o = V_{in} \cdot \frac{N_s}{N_p} \cdot D
\]

โดย \(D = t_{on}/T_s\) คือ duty cycle

### ข้อจำกัด Duty Cycle (reset winding 1:1)

ถ้าขดรีเซ็ต \(N_r = N_p\) เวลาที่ใช้รีเซ็ตฟลักซ์อย่างน้อยเท่ากับเวลา ON จึงต้อง

\[
D_{\max} < 0.5
\]

ถ้า \(N_r < N_p\) จะได้ \(D_{\max}\) สูงขึ้น แต่แรงดันบนสวิตช์ตอน OFF จะสูงขึ้นตามไปด้วย

### ความเครียดแรงดันบนสวิตช์ (reset 1:1)

\[
V_{DS,max} \approx 2\,V_{in}
\]

(ยังไม่รวม leakage spike — ต้องมี snubber/clamp ในทางปฏิบัติ)

### ตัวเหนี่ยวนำเอาต์พุต (ประมาณ ripple กระแส)

\[
\Delta I_L = \frac{(V_s - V_o)\,D\,T_s}{L}
\quad,\quad
V_s = V_{in}\frac{N_s}{N_p}
\]

### ตัวเก็บประจุเอาต์พุต (ประมาณ ripple แรงดัน)

\[
\Delta V_o \approx \frac{\Delta I_L}{8\,C_o\,f_s}
\]

(กรณีขยายจาก ripple กระแสสามเหลี่ยมผ่าน C เป็นหลัก)

## 5. การรีเซ็ตฟลักซ์ (ตัวเลือกที่พบบ่อย)

| วิธี | ข้อดี | ข้อควรระวัง |
|------|-------|-------------|
| **Tertiary / reset winding** | เรียบง่าย คลาสสิก | \(D_{\max}\) จำกัด, ต้องมีขดพิเศษ |
| **RCD clamp** | ใช้หม้อแปลง 2 ขดได้ | สูญเสียใน R |
| **Active clamp (P/N-channel)** | ประสิทธิภาพสูง, ZVS ได้ | วงจรควบคุมซับซ้อนกว่า |
| **Two-switch forward** | \(V_{DS}\) ต่อสวิตช์ ≈ \(V_{in}\) | ใช้ MOSFET 2 ตัว + ไดโอด 2 ตัว |

## 6. เปรียบเทียบกับโทโพโลยีใกล้เคียง

| | Forward | Flyback | Half-Bridge / Full-Bridge |
|--|---------|---------|---------------------------|
| ส่งพลังงาน | ตอน ON | ตอน OFF | ตอน ON |
| แกนหม้อแปลง | ไม่เก็บพลังงานหลัก (gap น้อย) | เก็บพลังงาน (มี gap) | ไม่เก็บพลังงานหลัก |
| ความซับซ้อน | ปานกลาง | ต่ำ | สูงกว่า |
| กำลังใช้งานทั่วไป | กลาง | ต่ำ–กลาง | กลาง–สูง |

---

## 7. จุดออกแบบที่มักพลาด

1. **ลืมรีเซ็ตฟลักซ์** → แกนอิ่มตัว, สวิตช์พัง
2. **Duty สูงเกิน \(D_{\max}\)** → รีเซ็ตไม่ทัน
3. **Leakage inductance** → spike บน MOSFET; ต้องมี snubber/clamp
4. **ไดโอดช้า** → ใช้ ultrafast / Schottky ที่แรงดันเหมาะสม
5. **ไม่แยก layout กำลังกับควบคุม** → สัญญาณรบกวน, วงจรแกว่ง
