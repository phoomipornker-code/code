# cv58-boost-v14-forward-v82

เปิดโฟลเดอร์นี้ใน Arduino IDE แล้ว Upload

## Boot
`[BOOT] cv58-boost-v14-forward-v82 | B_CC=6A F_CC=3A CV=55.90V DmaxF=460`

## สิ่งที่แก้ใน v82
- **Boost:** คืน BMS/OVP/runaway/spike ตาม `cv58-stability-v14-cv-stable`
- **Forward:** คง v75/v81 (ไม่ใช้ PID, ตาราง Serial ทุก 20 วินาที)
- `CAL_SCALE_V_BAT = 41.85`

## Flash
1. Arduino IDE → File → Open → เลือกโฟลเดอร์นี้
2. Board: ESP32
3. Upload
