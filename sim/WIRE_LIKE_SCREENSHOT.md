# ต่อ CC/CV แบบบล็อกในภาพ — ไม่ใช้ MATLAB Function

ได้ ใช้กล่องแบบเดิม (Constant, Sum, Gain, Integrator, Sat, Switch, คลื่น PWM)  
แต่ **ต้องต่อสายใหม่** — ห้ามให้ทั้งสองลูปออก Duty แล้วมา Switch

```text
ภาพเดิม (ห้ามใช้)          ต่อใหม่ (ตามเฟิร์มแวร์)
───────────────            ─────────────────────
CV PI ──┐                  CV PI ──► Iref (แอมป์ 0–3)
        ├─ Switch ─ Duty           │
CC PI ──┘                  Switch เลือก Iref=5 หรือ Iref จาก CV
                           CC PI(Iref−I) ──► Δduty
                           UnitDelay+Add ──► duty 0–460
                           ÷1023 ──► Duty 0–0.45 ──► แพลนต์ (PWM ดูอย่างเดียว)
```

---

## 1) เก็บครึ่งขวาของภาพ

เหลือ Saturation ของ Duty, คลื่น `Duty_Cy`, ตัวเทียบ `>=`, `[PWM]`  
ลบ Switch `> 55.8` และเส้นที่ `[CV]` / `[CC]` ต่อเข้า Switch

---

## 2) ลูปบน = แรงดัน → **Iref** (ของเดิมที่เขียน [CV])

ใช้ของเดิมได้ แค่เปลี่ยนค่าและเปลี่ยนป้ายว่าเป็นแอมป์

| บล็อก | ค่าใหม่ |
|---|---|
| Constant | **57.60** (เดิม 56.8) |
| Sum | `57.60 − [V_OUT]` |
| Gain P | **0.70** (เดิม 25) |
| Gain I | **0.35** (เดิม 4) |
| Integrator | `K·Ts/(z−1)` **Ts = 0.02** K = 1 |
| ZOH ของ P | **`-1`** ถ้าแพลนต์เป็นสวิตช์ต่อเนื่อง (ใส่ `0.02` แล้วซิมพังให้คืน `-1`) |
| Saturation หลังรวม P+I | **0 ถึง 3** (หน่วย A) |

แท็กเส้นนี้ว่า `[Iref_CV]` — **ห้ามต่อเข้า Duty**

เปิด Limit ของ integrator ถ้ามี: 0 ถึง 3 (กัน windup)

---

## 3) แทน Switch เดิมด้วย Relay + Switch ที่เลือก **Iref**

1. **Relay** (ไม่ใช่ Switch เทียบ 55.8)
   - เข้า: `[V_OUT]`
   - Switch on: **57.10**
   - Switch off: **56.40**
   - Output when on = 1 (โหมด CV)
   - Output when off = 0 (โหมด CC)
2. Constant `[I_CC]` = **5**
3. **Switch**
   - ขาบน (u1): `[Iref_CV]` จากข้อ 2
   - ขากลาง (u2): ออกจาก Relay
   - ขาล่าง (u3): `5`
   - Threshold = **0.5**
4. ออกจาก Switch = `[Iref]`

เมื่อ V สูงเกิน 57.10 ใช้ Iref จากลูปแรงดัน  
เมื่อ V ต่ำกว่า 56.40 ใช้ Iref = 5 A

---

## 4) ลูปล่าง = กระแส → **Δduty** (ของเดิมที่เขียน [CC])

อย่าลบลูปนี้ แค่เปลี่ยนอินพุตและเกน

| บล็อก | ค่าใหม่ |
|---|---|
| Sum | **`[Iref] − [I_OUT]`** (เดิมเป็น `5 − I_OUT` ตรงๆ) |
| Gain P | **8** (เดิม 0.5) |
| Gain I | **35** (เดิม 17) |
| Integrator | Ts = **0.02** |
| Saturation หลังรวม P+I | **−20 ถึง +25** |

แท็กว่า `[dDuty]` — ค่านี้ยัง **ไม่ใช่** Duty ที่เข้าคลื่น

---

## 5) สะสม duty (กล่องใหม่ 3 ตัว ต่อหลังลูปกระแส)

ภาพเดิมไม่มีจุดนี้ ต้องเพิ่ม:

```text
[dDuty] ──► Add ──► Sat 0..460 ──► [DutyRaw] ──► Gain 1/1023 ──► Sat 0..0.45 ──► Duty เข้าแพลนต์
              ▲
              └── Unit Delay 1/z   Sample time = 0.02
```

1. **Unit Delay** (`1/z`) — **ห้ามใช้ Memory แบบ Inherit**
   - Sample time = **`0.02`** (พิมพ์เอง อย่าปล่อย `-1`)
   - Initial condition = `0`
2. **Add**: `dDuty + Unit Delay`
3. **Saturation**: **0 ถึง 460**
4. ออก Sat วนกลับเข้า Unit Delay
5. **Gain** `1/1023`
6. ต่อเข้า Saturation สุดท้ายในภาพ ตั้ง **0 ถึง 0.45**
7. เส้น **Duty 0–0.45** นี้เข้าแพลนต์ (ค่าเฉลี่ย)  
   คลื่น `Duty_Cy` กับ `>=` ใช้ **ดูพัลส์อย่างเดียว** — ห้ามปิดลูปด้วย `[PWM]`

อย่าใส่ Integrator แบบ `Ts/(z−1)` ตรงนี้ — จะคูณ 0.02 ซ้ำ  
ใช้ Unit Delay + Add เท่านั้น (บวกทีละติ๊ก 20 ms)

---

## 6) Solver และตัวอย่างกระแส (ต้องทำ ไม่งั้น Duty สี่เหลี่ยม)

Fixed-step ของลูปควบคุม = **0.02**  
คลื่น 67 kHz ถ้าจะดูพัลส์ต้อง sample เร็วกว่า — **แต่ลูป PI ต้องช้ากว่า**

ก่อนเข้า Sum กระแส (`Iref − I_OUT`) ต้องมี **Low-Pass** เช่น Transfer Fcn `1/(0.02*s+1)`  
(กรองกระแสสวิตช์ให้เป็นค่าเฉลี่ย)

**Zero-Order Hold บนสัญญาณวัด (V_OUT / I_OUT / เส้น P):**

| สถานะซิม | ตั้ง Sample time |
|---|---|
| แพลนต์สวิตช์ 67 kHz, solver ต่อเนื่อง — ใส่ `0.02` แล้วโมเดลแดง/หยุด | **`-1`** (inherit) ← ใช้แบบนี้ |
| โมเดล discrete ทั้งก้อน ไม่มีคลื่น PWM ในลูป | `0.02` |

`0.02` คือรอบเฟิร์มแวร์บน ESP32 ไม่ใช่ค่าที่ ZOH วัดต้องบังคับในโมเดลสวิตช์  
ใส่ `0.02` ที่ ZOH วัดจะสร้าง rate transition ชนคลื่น 67 kHz จนซิมใช้ไม่ได้

รอบ 20 ms ในโมเดลสวิตช์ให้อยู่ที่ **Unit Delay ของ duty** ถ้าใส่แล้วซิมยังรันได้  
ถ้า Unit Delay `0.02` ทำให้พังเช่นกัน ให้เป็น `-1` ไปด้วย แล้วถือว่าซิมตรวจแค่เกน/สายไฟ — บนบอร์ดยังติ๊ก 20 ms

---

## 7) ถ้าเปลี่ยน Sat dDuty แล้วยังสี่เหลี่ยม 0↔0.45

**อย่าไล่ลิมิต Sat ต่อ** — ±4 กับ ±25 ให้รูปเดียวกันถ้าตัวสะสมบวกทุกสเต็ป PWM

สาเหตุ: กล่อง Memory / Integrator รันตาม solver (ไมโครวินาที) ไม่ใช่ 20 ms  
Kp=8 × (Iref−I) เมื่อ I เป็นพัลส์ 0 หรือ 15 A ทำให้ dDuty ชนเพดานทุกติ๊ก  
duty 0→460 ในเสี้ยววินาที → Scope เห็นสี่เหลี่ยม

ทำครบสามข้อนี้ แล้วค่อยรันใหม่ (SOC 70–90%, Stop time ≥ 5 s):

| ข้อ | ทำอะไร | ผิดแล้วเป็นอะไร |
|---|---|---|
| 1 | เปลี่ยน Memory เป็น **Unit Delay `1/z`**, Sample time **`0.02`** | Memory Inherit = บวกทุกสเต็ปคลื่น |
| 2 | ตัด `[PWM]` ออกจากแพลนต์ ต่อ **Duty 0–0.45** เข้าหม้อแปลง/แหล่งกระแส | พัลส์ 67 kHz ทำให้ I เป็น 0↔เต็ม |
| 3 | `[I_OUT]` → LPF → ZOH **`-1`** (โมเดลสวิตช์) → Sum กระแส | PI เห็นกระแสสวิตช์ ไม่ใช่ค่าเฉลี่ย |

หลังแก้แล้ว **คืน dDuty เป็น −20…+25** (ค่าเฟิร์มแวร์)  
ถ้า Unit Delay เป็น 0.02 จริง duty ไต่ทีละขั้น ไม่กระโดด 0↔0.45 ใน 0.2 s

ตรวจเร็ว: Scope `[DutyRaw]` (0–460)  
- ยังผิด: ขั้นบันไดถี่มากหรือสี่เหลี่ยมเต็มสเกลใน < 0.3 s  
- ถูก: ไต่ช้า ๆ หลักวินาที แล้วเกาะช่วง 80–250 ตอน CC

ตรวจ `[Iref]` ต้องเป็น **5** ตอน V < 57.1 (อย่าดูแท็ก CV ที่อิ่มที่ 3 A)

## สิ่งที่ยังไม่ครบเมื่อต่อแบบภาพ (ยอมได้ในซิม)

แบบบล็อกนี้ **ไม่มี**: SoftStart 2 s, ยืนยันเข้า CV 200 ms, taper ใกล้ 56.4 V, ลดเกนใกล้เป้า  
บนบอร์ดมีในโค้ด — ในซิมบล็อกนี้ยังเห็น CC → CV ถูกทาง

ถ้าต้องการครบทุกอย่างของเฟิร์มแวร์ ต้องใช้ `fwd_cccv_step` (MATLAB Function)
