# cv58-boost-v14-forward-v95

CV รักษาระดับแรงดัน: ถ้าแรงดันที่ ADS เห็น **เกินเป้า CV** ต้องลดดิวตี้ทันที

- ฟิลเตอร์แพ็กยังทิ้ง 90 V (ไม่ให้ SOC/OVP หลอก)
- แต่ลูป CV ใช้ `cvSenseVoltage()` รวมตัวอย่าง ADS นี้ — ถ้า I ยุบและ ADS > 62 V จะเห็น 90 V แล้วดึง Iref ลง / PWM ดับ
- Serial คอลัมน์ Vbat = ตัวอย่าง ADS รอบนี้, Vf = ค่าที่เชื่อว่าเป็นแพ็ก; เกิน CV มี note `CVhi`
