# Flowchart เข้าใจง่าย — มีหมายเลขลำดับ

แท็ก: `cv58-boost-v14-forward-v83`  
อ่านตามเลข **① → ② → ③ …**

---

## A) โหมด FORWARD (AC) — ไม่ใช้ PID

เป้า: SoftStart → CC 3 A → CV 55.90 V → เต็มแล้วหยุด

```mermaid
flowchart TD
    N1(["① เริ่ม FORWARD"]) --> N2["② SoftStart<br/>เปิด duty ช้า ๆ (+0.8)"]
    N2 --> N3{"③ พร้อมเข้า CC?<br/>duty พอ + มีกระแส<br/>หรือครบ 5 วินาที"}
    N3 -- ไม่ --> N2
    N3 -- ใช่ --> N4["④ CC<br/>รักษากระแส ≈ 3.0 A"]
    N4 --> N5{"⑤ Vbat ใกล้เต็ม?<br/>≥ 55.00 / force 55.30"}
    N5 -- ไม่ --> N4
    N5 -- ใช่ --> N6["⑥ CV<br/>คงแรงดัน ≈ 55.90 V"]
    N6 --> N7{"⑦ แบตเต็ม?<br/>slow 15s / fast 5s"}
    N7 -- ไม่ --> N6
    N7 -- ใช่ --> N8(["⑧ DONE / FULL<br/>duty = 0 หยุด PWM"])
    N6 -->|V ตก ≤ 54.50 นาน 5s| N4
    N8 -->|V ตก ≤ 54.0 และมี AC| N4
```

| ลำดับ | ความหมายสั้น ๆ |
|------:|----------------|
| ① | กด START โหมด FORWARD |
| ② | เปิด PWM ช้า ๆ ไม่กระแทก Cin |
| ③ | พร้อมแล้วค่อยไปดึงกระแส |
| ④ | ล็อกกระแสชาร์จ ~3 A |
| ⑤ | แรงดันขึ้นใกล้เต็ม → เข้า CV |
| ⑥ | ล็อกแรงดัน ~55.9 V |
| ⑦ | เช็คว่าเต็มจริง |
| ⑧ | เต็มแล้วหยุด |

## B) โหมด BOOST (PV) — ใช้ PI

เป้า: SoftStart → CC+MPPT 6 A → CV 56.00 V → เต็มแล้วหยุด

```mermaid
flowchart TD
    B1(["① เริ่ม BOOST"]) --> B2["② SoftStart<br/>เปิด duty หา seed"]
    B2 --> B3{"③ พร้อมเข้า CC?<br/>I ≥ 0.4 A หรือครบ 2.5 s"}
    B3 -- ไม่ --> B2
    B3 -- ใช่ --> B4["④ CC + MPPT<br/>รักษากระแส ≈ 6.0 A<br/>ปรับตามแผง"]
    B4 --> B5{"⑤ Vbat ใกล้เต็ม?<br/>≥ 55.50 / force 55.70"}
    B5 -- ไม่ --> B4
    B5 -- ใช่ --> B6["⑥ CV<br/>คงแรงดัน ≈ 56.00 V<br/>(หน่วง iReq ตามกำลัง PV)"]
    B6 --> B7{"⑦ แบตเต็ม?<br/>V≥55.90 และ I≤0.50 นาน 60s"}
    B7 -- ไม่ --> B6
    B7 -- ใช่ --> B8(["⑧ DONE / FULL<br/>duty = 0 หยุด PWM"])
    B6 -->|V ตก ≤ 54.20 นาน 5s| B4
    B8 -->|V ตก ≤ 54.0 และมี PV| B4
```

| ลำดับ | ความหมายสั้น ๆ |
|------:|----------------|
| ① | กด START โหมด BOOST |
| ② | เปิด PWM ช้า ๆ |
| ③ | พร้อมแล้วเข้า CC |
| ④ | ดึงกระแส ~6 A + ตามจุดกำลังแผง |
| ⑤ | ใกล้เต็ม → เข้า CV |
| ⑥ | คง ~56.0 V (ไม่ขอกระแสเกินที่แผงมี) |
| ⑦ | เช็คว่าเต็มจริง |
| ⑧ | เต็มแล้วหยุด |

## C) ภาพรวมทั้งระบบ (เลือกโหมด)

```mermaid
flowchart TD
    S1(["① STANDBY"]) --> S2["② กด STOP สลับโหมด<br/>BOOST ↔ FORWARD"]

    S7 --> S8
    S8 --> S1
```
