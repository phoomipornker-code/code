# 240 V + หม้อแปลง 48:21 — สัญญาณ Vout / Iout

จุดทำงานตามออกแบบ:

| | |
|--|--|
| Vac | **240 V** → บัส ~315–340 V |
| ขด | **48 : 21 : 48** · \(n=0.4375\) |
| D @ 58 V | **≈ 0.39** (ต่ำกว่า 0.45) |
| Iout CC | **5 A** ที่ ~54 V (CV 58 V รัดมาร์จิ้น D ที่หุบบัส) |
| L | 520 µH @ 67 kHz → \(\Delta I_L \approx 1\,\mathrm{A}\) |

## ที่สโคป 5 ms/div (สเกลเดียวกับรูปที่จับ)

- **Vout (CH1, 50 V/div):** เส้นเกือบตรงที่ **~54 V ตอน CC** (58 V ตอน CV) เพราะแบตยึดโวลต์ — ที่สเกลนี้มองไม่เห็นริปเปิล
- **Iout (CH2, 2 A/div):** ถ้า duty คงที่ ยังมีลูกคลื่น **100 Hz** จากบัส แต่เบากว่าเคส 110 V + 1:1.3 มาก ถ้าทำ \(D \propto 1/V_{in}\) กระแสจะค้าง ~5 A แทบเรียบ

## ที่สโคป 10 µs/div (ซูมดูสวิตช์)

- **Iout:** สามเหลี่ยมรอบ 5 A สูงประมาณ **1 A p-p** จังหวะ **67 kHz** — นี่คือของตัวเหนี่ยวนำ L ถือว่าปกติ
- **Vout:** ริปเปิลสิบ mV จาก ESR ของ \(C_o\) ต้องใช้สเกล 100 mV/div ถึงจะเห็น
