## วิธี ก — รันสคริปต์ MATLAB (แนะนำ)

### 1) เตรียมไฟล์

1. ดาวน์โหลดโฟลเดอร์ `sim` จากรีโป (หรือ PR) ให้ครบ 4 ไฟล์ในโฟลเดอร์เดียวกัน:
   - `forward_pi_reset.m`
   - `forward_pi_tick.m`
   - `run_forward_sim.m`
   - (อ่านอย่างเดียว) `README_FORWARD_SIMULINK.md`
2. วางไว้เช่น `D:\charger\sim\`

### 2) เปิด MATLAB

1. เปิด MATLAB
2. ที่แถบซ้าย **Current Folder** เข้าไปที่โฟลเดอร์ `sim`
3. หรือพิมพ์ใน Command Window:

```matlab
cd('D:\charger\sim')    % เปลี่ยนเป็นพาธของคุณ
pwd                     % ตรวจว่าอยู่ถูกโฟลเดอร์
```

ต้องเห็นไฟล์ `.m` ทั้งสามในหน้าต่าง Current Folder

### 3) รันจำลอง

ใน Command Window พิมพ์:

```matlab
run_forward_sim
```

รอประมาณ 1–2 วินาที จะขึ้นรูป 4 กราฟ และบรรทัดสรุป เช่น:

```text
End: V=57.12 V  I=1.74 A  duty=79  mode=2
```

`mode` : `0` = SoftStart, `1` = CC, `2` = CV, `3` = DONE

### 4) อ่านกราฟว่าถูกไหม

| กราฟ | ควรเห็น |
|---|---|
| Vbat | เริ่ม ~54 V ไต่ขึ้น แล้วชะลอใกล้ **57.6 V** |
| Ibat / Iref | ช่วงต้น Ibat ไล่ **Iref ≈ 5 A** ใกล้เต็ม Iref ลดลง |
| duty raw | SoftStart ไต่จาก 0 ไป ~80 แล้ว PI ดึงต่อ สูงสุดไม่เกิน **460** |
| mode | `SOFT` สั้นๆ → `CC` นาน → `CV` เมื่อ V ≥ 57.1 V |

ถ้า error `Undefined function forward_pi_tick` แปลว่า Current Folder ยังไม่ใช่ `sim`

### 5) ปรับการจำลอง (ถ้าต้องการ)

เปิด `run_forward_sim.m` แก้เฉพาะบล็อกบน:

| ตัวแปร | ค่าเดิม | ความหมาย |
|---|---|---|
| `Tstop` | 180 | ความยาวจำลอง (วินาที) |
| `Vac` | 220 | แรงดัน AC ที่วัดได้ |
| `v_nl` | 54.0 | โวลต์แบตตอนเริ่ม |
| `C_eq` | `5/0.02` | ยิ่งมาก โวลต์ขึ้นช้า (แพ็กใหญ่) |

แล้วรัน `run_forward_sim` อีกครั้ง  
**อย่าแก้เกนใน `forward_pi_tick.m`** ถ้าต้องการให้ตรงบอร์ด

## วิธี ข — รื้อภาพ Simulink เดิมทีละบล็อก

อย่าเริ่มจาก “เปลี่ยนตัวเลขในภาพ” ให้สร้างระบบควบคุมใหม่แล้วค่อยต่อเข้าแพลนต์/PWM เดิม

### 1) ตั้งเวลา

1. **Modeling → Model Settings → Solver**
2. Type: `Fixed-step`
3. Fixed-step size ของ **ตัวควบคุม** = `0.02`  
   (อย่าใส่ `1/67000` ที่นี่ — นั่นเป็นแค่คลื่น PWM)
4. ถ้ายังมี PWM 67 kHz ในโมเดล: ZOH บน V/I ตั้ง **`-1`** (inherit) — อย่าใส่ `0.02` ที่ ZOH วัด จะชนคลื่นแล้วซิมพัง

### 2) ลบของเก่าในภาพ

ลบหรือ bypass:

- Switch ที่เงื่อนไข `> 55.8`
- เส้นที่ลูป CV ต่อตรงเข้า Duty
- เส้นที่ลูป CC ต่อตรงเข้า Duty

เก็บได้แค่ `[V_OUT]`, `[I_OUT]`, คลื่น carrier, บล็อก PWM

### 3) สร้างลูปแรงดัน (ออกเป็นแอมป์)

1. Constant `57.60` ชื่อ `Vref`
2. Sum: `Vref − V_OUT`
3. PI แบบแยก P/I เหมือนภาพ แต่ค่าใหม่:
   - Gain P = `0.70`
   - Gain I = `0.35` แล้วเข้า Discrete Integrator `K*Ts/(z-1)` โดย **Ts = 0.02**, K = 1
4. Saturation เอาต์พุต PI: **0 ถึง 3** (หน่วยแอมป์ = Iref)
5. ใส่ anti-windup: ตอนอิ่มตัวไม่ให้อินทิกรัลเดินต่อ (เหมือน `boostRunPI`)
6. Rate Limiter หรือ slew: ± `0.06` แอมป์ต่อ 0.02 s

ยัง **ห้าม** ต่อเส้นนี้เข้า Duty

### 4) สร้างตัวเลือก Iref (แทน Switch)

ใช้ **MATLAB Function** หรือ Switch + Relay:

- โหมด CC: `Iref = 5` (เมื่อ V ≥ 56.40 ให้คูณ taper `(57.60−V)/(57.60−56.40)` จำกัด 0.10–1)
- โหมด CV: `Iref` = เอาต์พุตจากข้อ 3
- เข้า CV เมื่อ `V_OUT ≥ 57.10` นาน 0.2 s (หรือ ≥ 57.30 ทันที)
- กลับ CC เมื่อ `V_OUT ≤ 56.40` นาน 5 s

อย่าใช้เกณฑ์จุดเดียว 55.8

### 5) สร้างลูปกระแส (ออกเป็น Δduty)

1. Sum: `Iref − I_OUT`
2. PI:
   - Gain P = `8`
   - Gain I = `35`, Integrator Ts = `0.02`
3. Saturation ของ PI: **−20 ถึง +25**
4. เอาต์พุตนี้คือ **Δduty ต่อหนึ่งติ๊ก** ไม่ใช่ duty 0–1

### 6) สะสม duty แล้วค่อยทำ PWM

1. Discrete Integrator หรือ `Memory + Add` : `duty = duty + Δduty`
2. Saturation duty: **0 ถึง 460**
3. Slew ประมาณ ขึ้น 3 / ลง 5 นับต่อ 0.02 s
4. Gain `1/1023` ได้ D ทศนิยม
5. เทียบกับ carrier 67 kHz (`>=`) ได้ `[PWM]` เหมือนภาพเดิม
6. Sat หลัง Switch เดิมถ้าเป็น 0–1 ให้เปลี่ยนเพดานเป็น **0.45** หรือย้ายไปหลัง `1/1023`

### 7) SoftStart (มีในโค้ด ภาพเดิมไม่มี)

ตอน t = 0:

1. duty ไต่ไปที่ **80** (slew ขึ้น 1.5 นับ/ติ๊ก)
2. เมื่อ `I_OUT ≥ 0.35` หรือครบ **2 วินาที** จึงเข้าโหมด CC (ข้อ 4–5)

### 8) ตรวจผลใน Scope

ต่อ Scope:

1. `V_OUT` — เส้นอ้างอิง 57.6
2. `I_OUT` กับ `Iref` — ช่วง CC ทับที่ 5 A
3. `duty` (0–460) — ไม่เกิน 460
4. ธงโหมด Soft / CC / CV

ถ้า Ibat แกว่งรุนแรงตอนเข้า CV ตรวจว่าลูปแรงดันออกเป็น **แอมป์** จริง ไม่ได้ต่อเข้า PWM ตรงๆ

## สิ่งที่ยังไม่เหมือนบอร์ดจริง

สคริปต์ใช้แพ็กแบบคาปาซิเตอร์เทียบเท่า (โวลต์ขึ้นเร็ว เพื่อให้เห็น CC→CV ใน 3 นาที)  
บนแบต 20–100 Ah กราฟโวลต์จะนิ่งใน CC นานกว่ามาก แต่กฎ PI เดียวกัน

PWM 67 kHz ในวิธี ก ไม่ได้สวิตช์จริง เป็นค่าเฉลี่ย duty  
ถ้าต้องการ waveform สวิตช์ ให้ใช้วิธี ข แล้วต่อแพลนต์ Forward เดิมหลังบล็อก PWM
