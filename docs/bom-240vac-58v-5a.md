# สรุปอุปกรณ์ — AC 240 V → DC 58 V / 5 A

Single-switch forward + Nr · แกน ETD49 · **67 kHz**

## กำลังหลัก

| สัญลักษณ์ | อุปกรณ์ | ค่า / รุ่น |
|-----------|---------|------------|
| F1 | ฟิวส์ | 2.5 A ช้า / 250 VAC |
| BR1 | บริดจ์ | **GBU606** ≥ 600 V / 6 A |
| Cin | ตัวเก็บประจุบัส | **220 µF / 450 V** |
| Q1 | MOSFET | **STW20N95K5** + ฮีตซิงก์ TO-247 |
| T1 | หม้อแปลง ETD49 N87 | **48 : 21 : 48** ไม่เจาะ gap |
| Dr | ไดโอดรีเซ็ต | **UF4007** |
| D1, D2 | ไดโอดทุติยภูมิ | MUR860 หรือ SiC ≥ 200–300 V |
| L | ตัวเหนี่ยวนำเอาต์พุต | **500–540 µH**, \(I_{sat}>7\,\mathrm{A}\) |
| Co | ตัวเก็บประจุเอาต์พุต | **470–1000 µF / ≥ 80 V** + MLCC |

## RCD snubber (drain–source ของ Q1)

| สัญลักษณ์ | ค่า | หมายเหตุ |
|-----------|------|----------|
| Cs | **1 nF / 1–2 kV** | spike สูง → 1.5–2.2 nF |
| Rs | **100 Ω / 5–10 W** | wirewound; จูน 47–220 Ω |
| Ds | **UF4007** | วางใกล้ drain |

## ลวดหม้อแปลง (SWG 24)

ความลึกผิว @ 67 kHz ≈ 0.25 mm → พันหลายเส้นขนาน

กระสวย ETD49 MLT ≈ 85 mm + เผื่อ 15%

| ขด | รอบ × ขนาน | ความยาวลวด |
|----|------------|-------------|
| \(N_p\) | 48 × 2 | ≈ 9.4 m |
| \(N_s\) | 21 × 3 | ≈ 6.2 m |
| \(N_r\) | 48 × 1 | ≈ 4.7 m |
| รวม | | ≈ 20 m (ซื้ออย่างน้อย 25 m) |

## อินพุต / ความปลอดภัย

| รายการ | แนวทาง |
|--------|--------|
