# วงจรฟอร์เวิร์ดคอนเวอร์เตอร์ (Forward Converter)

Forward เป็นคอนเวอร์เตอร์สวิตช์ **isolated** ที่ส่งพลังงานจากปฐมภูมิไปทุติยภูมิ **ตอนสวิตช์เปิด** ต่างจาก Flyback ที่เก็บพลังงานในแกนแล้วคายตอนปิด

โครงมาจาก **Buck** โดยแทรกหม้อแปลงเพื่อแยกกราวนด์และตั้งอัตราส่วนแรงดัน

ชุดนี้เป็น **single-switch forward + tertiary reset winding \(N_r\)** สำหรับ AC 240 V → DC 58 V / 5 A

## 1. บล็อกในสคีมาติก

ดูภาพเต็มที่ `artifacts/forward_schematic.svg`

1. **อินพุต AC + เรกติไฟเออร์** — F1, บริดจ์ GBU606, \(C_{in}\) 220 µF / 450 V ได้บัสประมาณ 300–373 V
2. **สวิตช์ปฐมภูมิ** — MOSFET Q1 (STW20N95K5) ขับด้วย PWM 67 kHz, \(D \le 0.45\)
3. **RCD snubber** — ตัด leakage spike ไม่ให้ \(V_{DS}\) เกินเรตติ้ง 950 V
4. **หม้อแปลง T1** — ETD49, ขด \(48:21:48\), ไม่เจาะ gap
5. **ขดรีเซ็ต \(N_r\) + Dr** — คืนพลังงานแมกเนไทซิ่งเข้าบัสตอน Q1 ปิด
6. **ทุติยภูมิ** — D1 (forward), D2 (freewheel), L 520 µH, \(C_o\) → 58 V / 5 A

   D2 หัน **แคโทดขึ้น** ไปที่โหนด D1–L และ **แอโนดลง** กราวนด์ทุติยภูมิ — ตอน Q1 ปิด กระแส L ไหลกลับขึ้นผ่าน D2 ถ้าหันกลับด้าน D2 จะนำตลอดและชอร์ตเอาต์พุต

จุดสีบนขดคือ **ขั้วจุด (polarity)**

- \(N_p\) กับ \(N_s\) จุดเดียวกัน → ตอน Q1 เปิด แรงดันทุติยภูมิทำให้ D1 นำ
- \(N_r\) จุดกลับด้าน → ตอน Q1 ปิด Dr นำ รีเซ็ตฟลักซ์

กราวนด์ปฐมภูมิกับทุติยภูมิ **แยกกัน**

## 2. สองช่วงการทำงาน

ดู `artifacts/forward_on_off.svg`

### Q1 เปิด (\(0 < t < DT_s\))

- \(V_{in}\) ตกคร่อม \(N_p\) → ฟลักซ์ในแกนเพิ่มขึ้น
- \(v_s = V_{in}\cdot N_s/N_p\) → **D1 นำ**, **D2 ตัด**
- พลังงานไหลผ่าน D1 เข้า L ไปยังโหลด (เหมือน Buck ตอนสวิตช์เปิด)
- Dr ถูกไบแอสกลับ (เพราะ \(N_r\) จุดตรงข้าม)

### Q1 ปิด (\(DT_s < t < T_s\))

- D1 ตัด, กระแสใน L ไหลต่อผ่าน **D2**
- ฟลักซ์รีเซ็ตผ่าน \(N_r\) + Dr กลับเข้าบัส \(V_{in}\)
- เมื่อรีเซ็ตเสร็จ \(i_m = 0\) และ \(v_{DS} \approx V_{in}\) จนจบคาบ

ถ้าไม่รีเซ็ตฟลักซ์ให้ถึงศูนย์ทุกคาบ แกนจะอิ่มตัวแล้ว Q1 พัง

## 3. สมการหลัก

แรงดันเอาต์พุต (CCM, รวม \(V_f\) ของ D1):

\[
V_o + V_f = V_{in}\cdot\frac{N_s}{N_p}\cdot D
\]

ขีดจำกัด duty จาก volt-second บนขดรีเซ็ต:

\[
D_{\max} \le \frac{N_p}{N_p+N_r}
\]

เมื่อ \(N_r = N_p\) ได้ \(D_{\max} = 0.5\) — ชุดนี้ใช้ **0.45**

แรงดันบนสวิตช์ตอนรีเซ็ต (ยังไม่รวม leakage):

\[
V_{DS,\mathrm{reset}} \approx V_{in}\left(1+\frac{N_p}{N_r}\right) = 2V_{in}
\]

ที่ \(V_{in}=373\,\mathrm{V}\) ได้ ≈ **746 V** → MOSFET 950 V ยังมีมาร์จิ้น ถ้า leakage ถูก RCD ตัดไว้

## 4. คลื่นที่ควรเห็นบนออสซิลโลสโคป

ดู `artifacts/forward_waveforms.svg` (อุดมคติ CCM ที่ \(V_{in}=340\,\mathrm{V}\))

| ช่อง | รูปแบบ |
|------|--------|
| Gate | พัลส์ 67 kHz, กว้าง ≈ 0.39 · Ts |
| \(v_{DS}\) | 0 → \(2V_{in}\) ตอนรีเซ็ต → \(V_{in}\) หลังรีเซ็ตเสร็จ |
| \(v_{rect}\) (หลัง D1) | พัลส์ \(V_{in}n\) ตอน ON, 0 ตอน OFF |
| \(i_L\) | สามเหลี่ยมรอบ 5 A, \(\Delta I \approx 1\,\mathrm{A}\) |
| \(i_{D1}/i_{D2}\) | สลับกัน — ไม่นำพร้อมกัน |
| \(i_m\) | ขึ้นเชิงเส้นตอน ON, ลงเป็นศูนย์ตอนรีเซ็ต |

## 5. สิ่งที่มักพลาด

1. ลืมขด \(N_r\) หรือต่อขั้วจุดกลับ → แกนอิ่มตัว
2. Duty เกิน 0.45 → รีเซ็ตไม่ทัน
3. Leakage สูง (พันไม่ interleaved) → spike เกิน 950 V ทั้งที่มี RCD
4. ไดโอดช้าที่ D1/D2/Dr → recovery ร้อนและ EMI
5. รวมกราวนด์ปฐมภูมิกับทุติยภูมิ → เสีย isolation
